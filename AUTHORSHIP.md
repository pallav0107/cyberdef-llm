## Ground rules for this repository

1. **The git history must be Pallav's.** Initialise the repo and make every commit under
   his own name/email. Do **not** add any AI tool as a co-author or committer on this
   repository. Automated assistance may help draft text or scaffolding, but the authored
   work, the commits, and the published claims are his.

   ```bash
   git init
   git config user.name  "Pallav Pokhriyal"
   git config user.email "pallav01@gmail.com"
   git add .
   git commit -m "Initial release: cyberdef-vuln QLoRA study"
   ```

2. **No fabricated results, ever.** Every number in `MODEL_CARD.md`, `PAPER.md` and
   `RESULTS.md` is generated by `scripts/make_results_table.py`, which recomputes each score
   from recorded per-case model outputs and refuses (non-zero exit) on any mismatch. If you
   change a result, re-run a real evaluation; do not edit a number by hand.

3. **Publish only a defensible claim.** Do not publish this as a "contribution" while the
   recognized-benchmark delta is non-positive. A null or negative result is still a valid
   *authored report* (criterion-6 authorship) — present it as such, honestly.

4. **No commercial-API outputs as training data.** Training targets come from dataset ground
   truth, never from the outputs of a hosted commercial model. The base model (Qwen2.5-7B)
   is open-weight (Apache-2.0).
